# Umrah Flow data

`translations2_rows.csv` is generated from the supplied full Translations export and contains only keys referenced by the native SwiftUI Umrah Flow, including Tawaf Reading and the native stage/exit sheet.

`audio_urls_rows.csv` is the supplied Audio URLs export kept intact. Runtime content is loaded from Supabase; these CSV files are the isolated Umrah Flow data pack/reference for database import and QA.
